# LoginWebPage
# added login page with Realtime database of Firebase which only works for one month.
# has some features:
# Authentication Features

# Email and password login using Firebase Authentication
# New user registration (sign-up) functionality
# "Remember me" option to keep users logged in
# Password reset link (currently shows an alert, can be expanded to use Firebase's password reset functionality)
# Validation for registration form (password matching)
# Error handling for authentication failures

# Database Features

# User data storage in Firebase Realtime Database
# Records user information during registration (name, email, creation date)
# Tracks login activity (timestamp and device information)
# Updates user login status with each successful login
